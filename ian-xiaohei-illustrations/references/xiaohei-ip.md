# 王果果 IP

## 角色定义

王果果是这个配图 Skill 的固定视觉 IP。一个 6 岁左右的中国小女孩，认真但有点迷糊，像读者身边的小表妹，负责把抽象概念画成具体的事。

默认每张图都要出现王果果。果果不是吉祥物贴纸，不是可爱装饰，而是正在认真参与系统运转的小探索者。

## 外形（核心视觉锚点）

- **识别点：双丸子头 / 双发髻** — 黑色黑发，头顶左右两个圆圆的发髻（类似哪吒头或中式小女孩发髻），有少量碎发和刘海，发丝有流动感。
- **头身比**：约 2.5-3 头身的 Q 版比例，圆圆脸。
- **大眼睛**：棕色瞳孔，长睫毛，眼型偏圆，眼神好奇、真诚，不是夸张卡通大眼。
- **脸颊红晕**：淡淡的腮红，自然不夸张。
- **服装**：蓝白水墨质感的中式汉服 — 交领右衽，广袖或小袖，腰间系带，服装有明显的水彩色块晕染感，蓝色为主调，有深浅变化和少量墨色线条。
- **鞋子**：简单的蓝色布鞋。
- **肤色**：白皙，有水彩感。
- **线条**：墨线轮廓，略有水墨抖动感，不是机械直线。
- **表情**：认真、好奇、开心，嘴微张或带微笑，不是僵硬的。

## 性格

- **认真但有点迷糊**：在做一件正经事，但方式有点笨拙可爱。
- **好奇心强**：对一切新事物充满兴趣，喜欢探索、尝试。
- **像读者身边的小表妹**：亲切感，不是舞台上的表演者。
- **安静但有灵气**：不闹腾，不做夸张表情，但眼神有光。
- **小大人感**：做着超出年龄的事，但因为年龄所以显得有趣。

## 常见职责（核心动作）

让果果承担核心动作：

- **搬运素材 / 概念碎片**：双手抱着、推着或拉着什么。
- **拉线汇聚信息源**：一只手牵着一条线，线的另一端系着某个物件。
- **卡住 / 迷路**：坐在问题中间，表情有点困惑但不沮丧。
- **在系统里操作判断杆**：站在一个手绘装置前，伸手去拉/推/按。
- **变成筛选漏斗**：果果站在一个漏斗形状的装置里，让东西从她周围流过。
- **切开/撕开素材**：手里拿着一把大剪刀或撕开一张纸。
- **盖章 / 标记**：手里拿着一个印章或毛笔，在东西上盖印。
- **牵着路径走**：站在一条弯曲的路径上，手里拿着路径的一端。
- **举牌看路 / 看坑**：举着一个小牌子，上面写着关键词。
- **伸手接东西**：从洞里伸手，或者伸出双手去接飘过来的东西。
- **在旁边搬砖 / 搭桥 / 开门 / 分拣 / 记录**：做具体的、有画面感的事。
- **坐着思考 / 歪头想 / 叉腰看**：静态但有情绪的姿态。

## 禁止

- **不要把果果画成夸张的卡通吉祥物**。
- **不要画成大眼睛比例失衡的日漫角色**。
- **不要给果果复杂的华丽头饰、发饰、闪亮装饰**。
- **不要让果果只是站在角落里摆 pose**。
- **不要让果果抢走结构表达**。
- **不要画成成熟少女或成年女性形象**。
- **不要现代服装 / 运动装 / 校服**（除非构图明确需要对比）。
- **不要让动作夸张、表情夸张**。

## 判断标准

如果去掉果果，图的核心隐喻仍然能完全成立——说明果果太装饰了，要重写构图，让果果成为动作主体。
