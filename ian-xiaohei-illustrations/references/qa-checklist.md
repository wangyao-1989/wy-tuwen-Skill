# QA Checklist

## 必过项

- 是 16:9 横版。
- 背景是干净的宣纸白底。
- 有王果果（双丸子头必须清晰可见）。
- 王果果承担核心动作，不只是装饰。
- 没有复刻旧案例构图，而是为当前文章生成了新隐喻。
- 画面有童趣、有灵气、有创意。
- 简洁清爽，主体不超过画面约 60%。
- 一张图只讲一个核心结构。
- 中文标注少、短、能读（3-6 处，每处 2-6 字）。
- 主色是蓝白（水彩色块），墨色线稿，暖棕肤色，少量暖红点缀。

## 失败信号

出现以下情况，重生成或局部编辑：

- 左上角有"流程图 / Workflow / 系统架构图 / 路线图"等标题。
- 王果果像可爱贴纸、夸张卡通表情包。
- 王果果穿现代服装或发型不对（不是双丸子头）。
- 画面像 PPT、课程课件、正式流程图。
- 元素太多、箭头太多、节点太多。
- 文字变成大段解释。
- 背景有强烈纸纹、阴影、渐变、噪点。
- 真实 UI 截图或科技感界面。
- 中文错字严重或标注不可读。
- 画面太死板、太精致，没有童趣和水彩水墨感。
- 和 `assets/examples/` 里的旧案例构图过于相似。

## 迭代方法

- 太普通：让王果果成为动作主体，加入一个童趣但成立的隐喻。
- 太复杂：删节点，只保留一个动作和 3-5 个短标注。
- 太可爱：强调 curious / sincere / slightly lost / quietly focused，不要夸张表情、不要闪亮大眼睛。
- 太 PPT：去掉标题、边框、整齐网格和过多箭头，改成水彩手绘场景。
- 太像旧案例：保留核心意思，换掉主物件和王果果动作。
- 文字错：优先局部编辑；错得多就重生成并减少标注数量。
- 果果不像：检查双丸子头、蓝白汉服、6 岁比例 —— 这三个是核心识别点。

## 交付判断

高质量图应该让读者先"有点眼熟这个小女孩"，然后 1 秒内看懂结构。

如果第一眼像教程页、像可爱贴纸、像商业插画，而不是宣纸上的水彩儿童解释图，就不合格。
