# Ian 小黑怪诞正文配图

## 描述

为中文文章设计和生成 16:9 横版正文配图。目标不是做商业插画、PPT 信息图或可爱卡通，而是把文章里的关键判断、流程、结构、状态或隐喻，变成一张清爽、怪诞、有创意、可读但不说明书的手绘解释图。

默认视觉 IP 是"小黑"：黑色实心、白点眼、细腿、空表情，认真做一件荒诞但成立的事。小黑必须参与画面的核心动作，不能只是站在旁边当装饰。

## 使用场景

当用户表达以下意图时调用：

- 需要为一篇中文文章生成正文配图或文章插图
- 需要为某个概念、观点或方法生成一张解释图
- 需要配图策略、shot list 或配图规划
- 需要编辑/修改/去掉现有配图中的标题文字
- 需要为 Notion、博客、方法论文档、工作流文档配图
- 关键词：配图、插图、插画、画图、小黑、怪诞、手绘、正文配图、shot list、配图策略

## 前置准备

按任务需要读取以下参考文件，不要一次把所有内容塞进上下文：

- `ian-xiaohei-illustrations/references/style-dna.md`：风格 DNA、颜色、文字、禁忌
- `ian-xiaohei-illustrations/references/xiaohei-ip.md`：小黑 IP 的形象、性格、动作库和禁忌
- `ian-xiaohei-illustrations/references/composition-patterns.md`：结构类型、原创隐喻方法和反复刻规则
- `ian-xiaohei-illustrations/references/prompt-template.md`：单张生图提示词模板
- `ian-xiaohei-illustrations/references/qa-checklist.md`：生成后检查和迭代规则
- `ian-xiaohei-illustrations/assets/examples/`：只作低频视觉校准，不进入默认生成路径。不要照抄这些案例的构图、物件或标注。

## 工作流程

### 第一步：消化正文

先读用户给的正文、链接、Notion 页面、Markdown 文件或截图内容。提炼：

- 核心观点是什么
- 哪些段落承担认知转折
- 哪些内容适合用图解释
- 哪些地方只适合文字，不需要图

不要平均配图。优先选择"认知锚点"，例如：核心判断、两个断点、输入输出闭环、分流、前后对比、一鱼多吃、承接路径、常见坑、角色状态变化。

### 第二步：先出配图策略

如果用户只是说"分析怎么配图 / 思考哪些地方需要配图"，先给 shot list。每张图写清楚：

- 放在哪个段落后
- 图的主题
- 核心意思
- 结构类型
- 小黑在图里做什么
- 建议元素
- 建议中文标注词

默认 4-8 张。文章很短时 1-3 张；长文也不要轻易超过 9 张。够用就好，避免把正文做成画册。

### 第三步：单张生成

如果用户明确要求"生成 / 输出 / 做图 / 帮我生成"，直接开始生图。用图像工具每张单独生成。不要把多张图拼在一张里。

每张图只讲一个核心结构。提示词必须包含：

- 16:9 横版中文正文配图
- 纯白背景
- 黑色手绘线稿
- 少量红色/橙色/蓝色中文手写批注
- 大量留白
- 小黑作为核心动作主体
- 禁止 PPT、商业插画、幼稚可爱、复杂架构、左上角类型标题

不要复刻过往案例。案例只提供风格密度和小黑参与方式，不能直接复用已有构图。每次都要从当前文章重新发明一个奇怪但成立的隐喻。

### 第四步：检查与迭代

生成后对照 `ian-xiaohei-illustrations/references/qa-checklist.md` 进行检查。如果出现以下问题，优先重生成或局部编辑：

- 小黑只是装饰
- 画面太满
- 太像流程图/PPT
- 中文太多或错字严重
- 左上角出现"常见坑/流程图/系统架构图"等标题
- 画风太可爱、幼稚、死板
- 背景不是干净白底

### 第五步：保存交付

把最终图保存到以下路径：

```
assets/illustrations/
```

按顺序命名，例如：

```
01-topic-name.png
02-topic-name.png
```

保留原始生成文件，不要覆盖已有资产，除非用户明确要求替换。

## 输出规范

生成前的策略输出要短而准。生成后的交付要包含：

- 生成了几张
- 每张图的用途
- 保存路径
- 哪些图最稳，哪些图是可选

不要长篇解释风格理论；让图自己说话。

## 质量标准（验收清单）

生成的配图必须满足：

- 16:9 横版，干净纯白背景
- 黑色手绘线稿，细线，轻微抖动感
- 主体占画面约 40%-60%，至少 35% 留白
- 小黑承担核心动作，不是装饰
- 最多 5-8 处中文手写批注，每处 2-8 个字
- 一张图只讲一个核心结构
- 颜色克制：黑色为主、橙色主流程、红色重点、蓝色补充
- 怪诞、有创意、清爽，不可爱不幼稚
- 没有左上角类型标题，不像 PPT/流程图/课程课件
- 为当前文章生成了新隐喻，没有复刻旧案例构图

如果以上任何一项不满足，必须迭代重生成或局部编辑。
